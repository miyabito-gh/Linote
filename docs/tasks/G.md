# G: Markdown 変換

担当: Opus。共通指示は `_common.md`。

## 担当パス
`src/markdown/`。

## 要件
1. `pulldown-cmark` で HTML に変換。表、チェックリスト、取り消し線、脚注、コードブロック。
2. **埋め込み HTML を無効化**（生の HTML イベントはエスケープして表示）、リンクの `javascript:` 等の危険なスキームを無効化、画像・外部リソースを自動で読み込まない（`<img>` は出さずに代替テキストとリンク表示にする等。ローカル画像表示は初版対象外）。
3. 出力は完全な HTML 文書（CSP: `default-src 'none'; style-src 'unsafe-inline'` 等、スクリプトなし）。CSS は共通のテーマ（`ui` のテーマ型から色を受け取る。依存方向に注意し、色の値だけを受け取る純粋な関数にする）。見出し・段落・コードに余白。
4. 変換は入力が落ち着いてからバックグラウンドで行う仕組み（デバウンス）と、文書 ID・版の照合で古い結果を捨てる仕組み。右ペインと別ウィンドウで変換結果とスタイルを共有する。
5. 大きな文書でも UI を止めない。

## テスト
各要素の変換、HTML 無効化、危険なリンクの無効化、CSP の存在、古い版の結果の破棄。Linux ネイティブでもテストできるようにする。
