# J: 巨大ファイルの中核（部分読み込み・疎な行索引）

担当: Fable。メモリ上限・並行処理・無効化が要。共通指示は `_common.md`。

## 担当パス
`src/bigfile/`（GUI 非依存）。描画は L が担当する。

## 要件（`requirements.md` の巨大ファイル、推奨構成）
1. 1 GiB 級の UTF-8 ファイルを読み取り専用で開く。先頭を即座に表示できるよう、先頭のブロックだけ読んで最初の画面分の行を返す。
2. 疎な行索引: N 行ごと（または一定バイトごと）のオフセットを記録。残りの索引はバックグラウンドで作成し、進捗を通知、中止可能。行ジャンプは索引から近い位置を探して前方走査。
3. 長大な単一行: 1 行が数百 MiB でもメモリが膨らまないよう、行内を一定バイトで区切った「表示上の行（セグメント）」として扱う。UTF-8 の文字境界をまたがない。
4. 範囲読み取り API（表示範囲・範囲コピー用）。ブロックキャッシュの上限（メモリ予算）を設け、LRU 等で捨てる。メモリ予算は設定値として受け取る。
5. 検索: 文字列検索と正規表現検索（行単位、`regex::bytes`）を、指定位置から前方／後方へ。最初のヒットを早く返す。中止可能。大文字小文字の扱い。長大行の正規表現は区切り単位で行い、制約を API の戻り値で表す（UI が案内できるように）。
6. 外部変更: ファイルの切り詰め・置換を検知したら、索引・キャッシュ・検索結果を無効化してエラーを返す。
7. ファイルは共有読み取りで開き、他のアプリの書き込みを妨げない（Windows の共有モード）。

## テスト
`scripts/gen-large-fixtures.py` で生成したデータ（テストでは小さめのサイズで生成）を使い、行ジャンプ・範囲読み取り・検索・中止・長大行・切り詰めの無効化・メモリ上限を検証。1 GiB での計測手順を報告に書く（Linux ネイティブで計測した値も参考に記録）。
