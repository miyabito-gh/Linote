# L: 巨大ファイルの表示（DirectWrite）

担当: Opus。J の完成後に着手。共通指示は `_common.md`。

## 担当パス
`src/ui/bigview.rs`（巨大ファイル用のビュー）。

## 要件
1. J の API で表示範囲だけを取得し、Direct2D／DirectWrite で描画する独自コントロール。行番号、スクロール（縦: 索引作成中は推定でスクロールバーを出す、横）、選択（範囲コピー用）、`Ctrl+C`、`Ctrl+G` 行ジャンプ、`Ctrl+End` 末尾移動、検索ヒットの強調。
2. 折り返しと構文着色は既定でオフ。読み取り専用であることを画面に表示（ステータスバーの表示は B と連携）。
3. 長大行は J のセグメント単位で表示。描画とキャッシュに上限。
4. テーマと DPI に追従。
5. タブとして通常文書と同じように扱える（文書種別: 巨大読み取り専用）。

## テスト
Wine＋Xvfb で開いて、スクロール・行ジャンプ・コピーが動く範囲の自動テスト。性能・見た目は Windows 実機確認項目として報告。
