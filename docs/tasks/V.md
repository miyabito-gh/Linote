# 改善タスク V1〜V3（一般のエディタとの比較による指摘、2026-11-14）

担当: Sonnet（1 つずつ順に実施）。共通指示は `_common.md`。U と同じく、統合作業として `src/ui/` 全体、`src/main.rs`、`src/command/` の既定キー、`src/appdata/settings.rs`、`src/memo/`（V2 のみ）、`Cargo.toml`（`windows` の機能フラグのみ）の編集を許可する。変更した挙動は `docs/spec.md` に反映し、Windows 実機の確認項目を `docs/verification/V.md` に追記する。

**テストは関係するものだけ回す**（例: `cargo test --lib --target x86_64-unknown-linux-gnu <モジュール名>`、変更した UI の自己診断）。全体の品質関門は統括が最後に 1 回行う。ただし `cargo build` と `cargo clippy --all-targets -- -D warnings` は報告前に通す。

## V1: 起動・終了とウィンドウ

1. **無題タブを無条件に作らない。** 文書が 0 件の状態を許す。
   - 起動時: 開くファイルも受け渡し（`--adopt`）も前回のタブの復元もなければ、文書 0 件で起動する。
   - **不具合修正**: タブを切り離して新しいプロセスを起動すると無題タブが余分にできる。原因は `src/ui/app/mod.rs` の `run` で、`adopt_handoff`／`open_path` の読み込みが非同期（`self.opening`）なのに `app.docs.is_empty()` だけで判断して `new_untitled()` していること。
   - 最後のタブを閉じたとき（`close_document`）、「すべて閉じる」の後、開くのに失敗したとき（`ensure_a_document`）も無題を作らず 0 件にする。
   - 0 件のときは編集欄（Scintilla）を隠し、本文の場所に簡単な案内（「Ctrl+N 新規　Ctrl+O 開く」と最近使ったファイル数件。クリックで開ければなおよい。難しければ文字だけ）をテーマの色で描く。タブバーのダブルクリックで新規は従来どおり。
   - 0 件のときに文書を前提とするコマンド（保存、検索、印刷、編集、表示のうち文書に作用するもの、プレビュー等）は実行不可（メニュー無効、ショートカットは何もしない）。`active: Option<usize>` が `None` になる経路をすべて点検し、パニックしないこと。ステータスバーの文書情報は空にする。
2. **前回のタブを復元。** 正常終了時（すべての確認を通って終了するとき）に、ファイルのある通常文書と巨大文書のパス・タブ順・アクティブなタブ・カーソル位置（先頭行の位置も可能なら）を `%LOCALAPPDATA%\Linote\session.json` に原子的に書く（`appdata` の既存の書き込み関数を使う）。起動時に引数・`--adopt` がなければ読み、存在するファイルを開いて順序とカーソルを戻す（存在しないものは黙って飛ばす）。無題・メモ・クリップボード由来は対象外（未保存分は既存の復元データが担う）。複数ウィンドウでは最後に終了したウィンドウの内容が残る（それでよい）。設定 `restore_session`（真偽値、既定 `true`）で無効にできる。起動を重くしないこと（読み込みは既存の非同期の開く処理を使う）。
3. **ウィンドウの位置・大きさ・最大化の記憶。** 終了時に `GetWindowPlacement` を `settings.json` の `window` に保存し、起動時に復元する（`--adopt` で位置指定があるときはそちら優先）。画面外になる場合はモニターの作業領域内に収める。
4. **矩形選択の確認。** Alt＋ドラッグと Alt＋Shift＋矢印は `src/ui/editor/mod.rs` で設定済み。Alt を離したときにメニューバーへフォーカスが移って入力が奪われないか確認し、移るなら Alt＋ドラッグの後の `WM_SYSKEYUP`（VK_MENU）をメニューに渡さないようにする。編集メニューに「矩形選択」（`edit.rectangular_select`、次のマウス選択・矢印選択を矩形にする切り替え。`SCI_SETSELECTIONMODE`）を追加する。

合格条件: 0 件状態・セッションの読み書き（純粋関数・JSON の往復）・ウィンドウ位置の補正の単体テスト、自己診断で 0 件起動・最後のタブを閉じる・タブの受け渡しで無題ができないことを確認。

## V2: タブとメモの小物

1. **すべて保存**（`file.save_all`、Ctrl+Alt+S は既存のグローバルキーと衝突しないか確認して決める）。変更のある文書を左から順に保存。名前のない文書は保存ダイアログを出し、取り消したらそこで止める。メモは保存、巨大は対象外。
2. **閉じたタブを開き直す**（`file.reopen_closed`、Ctrl+Shift+T）。閉じたファイルのパスとカーソル位置を最大 20 件まで覚え（その起動の間だけ）、新しいものから開く。ファイルがなければ飛ばして次へ。メモは ID で開き直す。
3. **メモの削除**: メモ一覧の小窓に「削除」ボタンと Delete キー。確認ダイアログを出し、`MemoStore::delete` を版付きで呼ぶ。開いているタブがあれば閉じる。版の不一致は通知して削除しない。
4. **言語の手動選択**（表示 > 言語、`view.language`、引数 `language`）。対応言語の一覧と「なし（プレーンテキスト）」「拡張子から自動」。文書ごとに保持（保存しない）。ステータスバーの言語名に反映。

## V3: 検索

1. **検索・置換の履歴**: 検索欄・置換欄・Grep の起点欄をドロップダウン付き（`CBS_DROPDOWN`）にし、実行した語を新しい順に最大 20 件、`settings.json` の `search_history`（`find`／`replace`／`grep_dir`）に保存。重複は先頭へ。
2. **選択範囲内の検索**: 「選択範囲内のみ置換」を「選択範囲内」に一般化し、次へ・前へ・全一致の強調・件数も選択範囲に限定する。オンにした時点の選択範囲を Scintilla のインジケーターで示して保持する（編集で範囲がずれても追従するようインジケーターから範囲を読む）。
