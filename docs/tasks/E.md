# E: 一時メモ

担当: Opus。共通指示は `_common.md`。

## 担当パス
`src/memo/`（保存・検索のロジック）、`src/ui/memo_panel.rs`（検索できる小窓）。

## 要件
1. メモは複数。`%LOCALAPPDATA%\Linote\memos\` に UTF-8 で 1 メモ 1 ファイル（＋必要なら索引）。名前・本文・作成・更新時刻・版。原子的に書く。
2. 入力が落ち着いた時点と正常終了時に自動保存。保存は UI スレッド外。
3. 一覧は初めて開くときに読み込む（起動時に読まない）。名前・本文で検索（大文字小文字・全角半角の扱いを決める）。
4. 別プロセス・複数ウィンドウから同じメモを扱っても上書きし合わない（版の照合で衝突を検出し、衝突時は別名で残すなど方針を決めて実装）。
5. 小窓 UI: エディタ内のショートカット（キーは統括がコマンドとして割り当てる。コマンドの実装関数を用意）で開き、検索欄＋一覧、選択したメモをタブで開く、新規メモ作成、閉じると本文にフォーカスを戻す。テーマに合わせる。
6. メモをタブで開いたときの文書種別（`architecture.md` のメモ種別）と保存の流れ（ファイル保存ではなくメモ保存）。

## テスト
保存・読み込み・検索・衝突検出の単体テスト（Linux ネイティブでも）。小窓は Wine＋Xvfb で開閉できること。
