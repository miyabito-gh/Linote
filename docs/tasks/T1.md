# T1: テストデータ生成スクリプト

担当: Sonnet。定型作業。

## 目的

文字コード・改行・巨大ファイルのテストに使うデータを、リポジトリに大きなファイルを入れずに生成できるようにする。

## 成果物

1. `tests/fixtures/` に小さな固定テストデータ（各数 KB 以下）:
   - UTF-8（BOM なし／あり）、UTF-16LE（BOM あり）、UTF-16BE（BOM あり）、CP932（Shift_JIS、日本語・半角カナ・機種依存文字 ①Ⅱ㈱ を含む）。
   - 改行 CRLF／LF／CR／混在、末尾改行なし、空ファイル。
   - CP932 に変換できない文字（例: 絵文字 😀、𠮷）を含む UTF-8。
   - 内容と期待値（文字コード、BOM、改行形式）を書いた `tests/fixtures/README.md`。
   - 生成はスクリプトで行い、生成物もコミットする（`.gitattributes` で `tests/fixtures/** -text` 済み）。
2. `scripts/gen-large-fixtures.py`（Python 3 標準ライブラリのみ）: 引数で出力先とサイズを指定し、巨大ファイルを生成する。
   - 短い行が大量（例: 1 GiB、各行 80 バイト前後、行番号入りで行ジャンプの検証ができる形式）。
   - 長大な単一行（改行がほぼない、例: 256 MiB の 1 行＋数行）。
   - 100 MiB 級の UTF-8 日本語混在ファイル（編集・保存の性能確認用）。
   - 乱数は固定シードで再現可能に。出力は既定で `target/fixtures-large/`（git 管理外）。
   - 検索ヒットの検証用に、既知の位置に既知の文字列を埋め込み、その位置（バイトオフセット・行番号）を JSON で出力する。
3. `docs/PLAN.md` の T1 の行を「👀 レビュー中」に更新する。

## 制約

担当パスは `tests/fixtures/`、`scripts/gen-large-fixtures.py`、`docs/PLAN.md` の T1 の行のみ。Rust コードは変更しない。

## 合格条件

`python3 scripts/gen-large-fixtures.py --help` が動き、小さいサイズ指定（例: 1 MiB）で全種類を生成できる。固定テストデータの内容が README の記載と一致する。

## 報告

作成したファイルと使い方を簡潔に。作業ブランチにコミットすること（push しない）。
