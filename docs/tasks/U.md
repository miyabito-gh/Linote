# 改善タスク U1〜U4（初版の利用者フィードバック、2026-11-14）

担当: Sonnet（1 つずつ順に実施）。共通指示は `_common.md`。このタスク群では、統合作業として `src/ui/` 全体、`src/main.rs`、`src/command/` の既定キー、`src/appdata/settings.rs`、`Cargo.toml`（`windows` の機能フラグのみ）の編集を許可する。仕様の正本は `docs/spec.md`（実装どおりの仕様）で、変更した挙動は `docs/spec.md` にも反映する。

## 利用者からの要望

1. 「開く」ダイアログの既定の種類が `*.txt` になっている。一般的なテキストファイルは種類を変えなくても最初から表示されるようにする。
2. ファイルをウィンドウにドラッグ＆ドロップして開けるようにする。
3. 行の折り返し方法を指定できるようにする。
4. 検索時は該当する文字をすべて強調表示する。F3／Shift+F3 で次へ・前へ移動できるようにする。
5. タブをウィンドウの外にドラッグしたら、新しいウィンドウで開く。
6. 一般的なテキストエディタにある基本機能で、Linote にないものを使えるようにする。

## U1: ファイル操作の改善

- 開くダイアログの種類: 既定は「すべてのファイル (*.*)」。ほかに「テキストファイル」（txt, log, md, markdown, csv, tsv, json, xml, html, htm, css, js, ts, rs, c, h, cpp, hpp, cs, java, py, ps1, bat, cmd, sql, ini, toml, yaml, yml, cfg, conf, properties など）を選べる。複数選択で複数のタブを開く。名前を付けて保存も同様に「すべてのファイル」を既定にする。
- ドラッグ＆ドロップ: ウィンドウ（本文、タブバー含む）にファイルをドロップすると開く（`DragAcceptFiles`／`WM_DROPFILES`）。複数可。フォルダーは無視して状態表示。既に開いているファイルはそのタブへ移る。
- 最近使ったファイル（ファイルメニューに最大 10 件、設定に保存、存在しないものは選んだときに案内して一覧から外す）。
- 「ディスクから再読み込み」（未保存の変更があれば確認）。
- 「すべて閉じる」「他のタブを閉じる」。
- 「新しいウィンドウ」（Ctrl+Shift+N。新しいプロセスで起動）。
- 保存時の文字コード・改行の変更: 「名前を付けて保存」または専用メニューで、保存時の文字コード（UTF-8、UTF-8 BOM、UTF-16LE/BE、CP932）と改行（CRLF／LF／CR）を選べる。ステータスバーの表示も更新。
- 「フルパスをコピー」「エクスプローラーで表示」。

## U2: 表示の改善

- **折り返し**（表示メニュー）: しない／ウィンドウ幅で折り返す（単語単位）／ウィンドウ幅で折り返す（文字単位）／指定した桁で折り返す（桁数を入力、既定 80。Scintilla の折り返し幅をその桁に合わせる）。折り返した行のインデント保持。設定に保存。巨大モードは対象外。
- 書体と文字サイズの指定（フォント選択ダイアログ）、拡大・縮小（Ctrl+マウスホイール、Ctrl+＋／Ctrl+−、Ctrl+0 で元に戻す）。
- 空白・タブ・改行記号の表示切り替え、行番号の表示切り替え、現在行の強調、対応する括弧の強調、折り返し桁のガイド線（指定桁のとき）。
- タブ幅（2／4／8）とタブをスペースで入力するかの切り替え、自動インデント。
- これらは設定に保存し、全タブに適用する。

## U3: 検索と編集の改善

- **検索の強調表示**: 検索欄の入力に合わせて、表示中の文書のすべての一致を Scintilla のインジケーターで強調（大きい文書は表示範囲の付近から、上限件数あり、ワーカーまたは段階的に）。現在の一致は別の色。検索欄を閉じても強調は残し、Esc または文書の編集で消す。件数「n / 全 m 件」を検索欄に表示。
- **F3／Shift+F3**: 検索欄が閉じていても、直前の検索条件で次・前へ移動。条件がなければ選択中の文字列（なければカーソル位置の単語）で検索を始める。Ctrl+F3 で選択中の文字列を検索語にして次へ。巨大モードでも同様。
- 選択範囲内の置換。
- 編集コマンド: 行の複製（Ctrl+D）、行の削除（Ctrl+Shift+K）、行を上下に移動（Alt+↑／↓）、大文字・小文字の変換、行末の空白の削除、タブ⇔スペースの変換、日時の挿入、対応する括弧へ移動（Ctrl+]）。

## U4: タブの操作

- タブのドラッグで並べ替え。
- **タブをウィンドウの外にドラッグして離すと、新しいウィンドウ（新しいプロセス）でその文書を開き、元のタブを閉じる。**
  - 保存済みの文書は、パスを渡して新しいプロセスで開く。
  - 未保存の変更がある文書・無題の文書は、内容（文字コード、改行、元のパス、未保存状態）を受け渡し用のファイル（`%LOCALAPPDATA%\Linote\handoff\`、原子的に書く）に書いて、`linote.exe --adopt <ファイル>` で起動する。新しいプロセスは読み込んだら受け渡しファイルを削除し、未保存として扱う（復元データの対象にする）。新しいプロセスの起動を確認してから元のタブを閉じる。失敗したら元のタブを残して知らせる。
  - メモのタブは、新しいウィンドウで同じメモを開く（メモの版の照合で整合を保つ）。巨大ファイルのタブはパスを渡す。
  - 離した位置に新しいウィンドウを置く。
- タブの右クリックメニュー: 閉じる、他を閉じる、右側を閉じる、新しいウィンドウに移動、フルパスをコピー、エクスプローラーで表示。

## 共通の合格条件

- 既存のテストと自己診断を壊さない。追加した機能は自己診断かテストで確認できる範囲を確かめる。
- 品質関門（fmt、clippy、Wine＋Xvfb の `cargo test`、Linux ネイティブの lib テスト、release ビルドと `check-imports.sh`、`--self-test`）。
- 起動を重くしない（最近使ったファイルの読み込みは設定の読み込みの範囲で、存在確認はしない）。
- `docs/spec.md` の該当章と「コマンドとキー割り当て一覧」を更新する。Windows 実機の確認項目を `docs/verification/U.md` に追記する。
