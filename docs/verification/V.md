# 改善 V1 の Windows 実機確認

Wine＋Xvfb の自己診断（`linote.exe --self-test`）で通る範囲（0 件起動、最後のタブを閉じる、受け渡しで無題ができない、セッションの記録と復元の順序・カーソル、ウィンドウ位置の取得と戻し、矩形選択の切り替え）は済んでいる。ここは**実機でしか確かめられない**項目。

## V1 起動・終了とウィンドウ

### 文書 0 件

- [ ] 引数なしで初回起動（`%LOCALAPPDATA%\Linote\session.json` がない）すると、タブが 1 つもなく、本文の場所に「Ctrl+N 新規　Ctrl+O 開く」と案内が出る（無題のタブができない）。
- [ ] 最近使ったファイルがあれば、案内の下に最大 5 件が出る。マウスを乗せると手の形になり、クリックで開く。存在しないファイルをクリックすると、「見つかりません。一覧から外しました」が出る。
- [ ] 案内の文字色・背景がライト／ダークのテーマに合っている。テーマ切り替え（表示 > テーマを切り替え）で描き直される。ウィンドウの大きさを変えても中央寄りに描かれ、はみ出さない。高 DPI（150%・200%）でも文字が小さすぎず、行間が詰まらない。
- [ ] 0 件のとき、ファイル > 上書き保存／名前を付けて保存／閉じる／印刷、編集のほとんど、検索メニューの検索・置換・次へ・前へ、表示 > 次のタブ／前のタブ／Markdown プレビューがグレーになる。新規・開く・最近使ったファイル・新しいウィンドウ・Grep・メモは使える。Ctrl+S、Ctrl+F、Ctrl+Tab などのショートカットは何も起こらない（エラーも出ない）。
- [ ] 最後のタブを閉じる（×、Ctrl+W、中クリック）と 0 件の案内になり、無題は作られない。ステータスバーの行・列・文字コードなどが空になり、ウィンドウの題名が「Linote」になる。「すべて閉じる」も同様。
- [ ] 0 件の状態で Ctrl+N、Ctrl+O、タブバーのダブルクリック、ファイルのドラッグ＆ドロップ、クリップボード展開のグローバルショートカットが使える。開いたあとは編集欄にフォーカスがあり、すぐ入力できる。
- [ ] タブを別ウィンドウへ切り離す（タブバーの外へドラッグ）と、新しいウィンドウには移したタブだけがあり、余分な無題のタブができない。移した元のウィンドウで、それが最後のタブでなければ従来どおり残りが表示される。
- [ ] 存在しないファイル、読めないファイルをコマンドラインに渡して起動すると、状態表示で失敗が分かり、0 件の案内になる（無題ができない）。

### 前回のタブの復元

- [ ] 3 つのファイルを開き、2 番目をアクティブにしてカーソルを途中に置き、少しスクロールして終了（未保存なし）。再起動すると、同じ順序で 3 つ開き、2 番目がアクティブで、カーソルの位置と表示の先頭行がほぼ戻る。起動が遅くならない（ウィンドウがすぐ出る）。
- [ ] 無題・メモ・クリップボード由来のタブは復元されない（未保存の無題は従来の復元ダイアログで戻る）。巨大ファイルのタブはパスと順序が戻る（カーソルは戻らない）。
- [ ] 記録後にファイルを削除・改名して起動すると、そのファイルは黙って飛ばされ、残りが開く。全部なくなっていれば 0 件の案内になる。
- [ ] コマンドラインでファイルを渡して起動すると、前回のタブは開かず、渡したファイルだけが開く。そのウィンドウを閉じると、記録はそのウィンドウの内容になる（最後に終了したウィンドウが残る）。
- [ ] `settings.json` に `"restore_session": false` を書くと、復元されず（0 件で起動）、終了時に `session.json` も更新されない。
- [ ] 未保存の変更があって「取り消し」で終了を止めた場合は記録されない。確認を通って終了したときだけ記録される。タスクマネージャーでの強制終了では記録が古いままになる（仕様）。
- [ ] `session.json` を壊して（`{` だけにして）起動しても、エラーなく 0 件で起動する。

### ウィンドウの位置と大きさ

- [ ] ウィンドウを移動・リサイズして終了し、再起動すると同じ位置・大きさで出る。最大化して終了すると、最大化で起動し、元に戻す（復元）ボタンで終了前の通常の大きさに戻る。最小化したまま終了しても、最小化前の状態で起動する。
- [ ] 2 台目のモニターに置いて終了し、そのモニターを外して（または解像度を下げて）起動すると、ウィンドウがいちばん近い画面の作業領域の内側に出る（画面外に消えない）。タスクバーに隠れない。
- [ ] モニターごとに DPI が違う環境で、2 台目に置いたウィンドウを再起動しても、大きさが極端に変わらない。
- [ ] タブを切り離して新しいウィンドウを作ると、離した位置に出る（記録した位置より優先する）。
- [ ] 設定ファイルが壊れているとき、ウィンドウの位置は書かれない（上書きしない）。

### 矩形選択と Alt

- [ ] 編集 > 矩形選択にチェックを付けてから、マウスのドラッグ（Alt なし）や Shift+矢印で選択すると矩形になる。もう一度選ぶとチェックが外れ、通常の選択に戻る。巨大ファイルでは無効（グレー）。
- [ ] Alt＋ドラッグで矩形選択をして Alt を離しても、メニューバーが有効にならない（ファイル（F）などが反転せず、続けて入力・矢印キーが本文に効く）。Alt＋Shift＋矢印で矩形選択を伸ばして Alt を離したときも同様。
- [ ] Alt だけを押して離すと、従来どおりメニューバーが有効になる（F10 も同様）。Alt+F などのメニューのアクセスキーも従来どおり開く。
- [ ] Alt＋ドラッグの矩形選択のあと、Alt を押したまま離さずに（キーリピートが入るほど長く）ドラッグしても問題ない。
- [ ] 日本語 IME をオンにした状態でも、Alt＋ドラッグ・Alt を離す操作でフォーカスやモードが乱れない。
