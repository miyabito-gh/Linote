# 改善 U1〜U4 の Windows 実機確認

Wine＋Xvfb の自己診断（`linote.exe --self-test`）で通る範囲は済んでいる。ここは**実機でしか確かめられない**項目。

## U1 ファイル操作

### 開くダイアログ

- [ ] Ctrl+O の種類の既定が「すべてのファイル (*.*)」で、`.txt` 以外（`.log`、`.json`、拡張子なしなど）が最初から一覧に出る。
- [ ] 種類を「テキストファイル」にすると、txt／log／md／csv／json／xml／html／css／js／ts／rs／py／ini／toml／yaml などだけに絞られる。
- [ ] 複数選択すると、それぞれがタブで開く。
- [ ] 名前を付けて保存（Ctrl+Shift+S）の種類の既定も「すべてのファイル」。拡張子を省くと `.txt` が付く。

### ドラッグ＆ドロップ

- [ ] エクスプローラーからファイルを**本文**にドロップすると開く（カーソルが複写の形になる）。
- [ ] **タブバー**・**状態表示**・メニューの下の余白にドロップしても開く。
- [ ] 複数ファイルを一度にドロップすると、全部がタブになる。
- [ ] フォルダーをドロップしても開かず、状態表示に「フォルダーは開けません」が出る（ファイルと混在でもファイルは開く）。
- [ ] 既に開いているファイルをドロップすると、新しいタブでなく既存のタブへ移る。
- [ ] 巨大ファイル（読み取り専用ビュー）の表示中にドロップしても開く。
- [ ] 本文内で選択した文字列をドラッグして移動・複写する操作が、従来どおり動く（ファイルのドロップ対応で壊れていない）。
- [ ] 他のアプリ（ブラウザーなど）からテキストを本文へドロップすると、挿入される。
- [ ] 管理者権限で起動した Linote には、通常権限のエクスプローラーからドロップできない（Windows の仕様）ことを確認し、案内が必要か判断する。

### 最近使ったファイル

- [ ] ファイル > 最近使ったファイルに、開いた順に最大 10 件が出る。初回は「(なし)」（灰色）。
- [ ] 項目を選ぶと開く。既に開いていればそのタブへ移る。
- [ ] 名前を付けて保存したファイルも一覧に入る。
- [ ] 長いパスは中ほどが「...」で省かれ、`&` を含むパスが正しく表示される。
- [ ] 一覧のファイルを削除してから選ぶと、「見つかりません。一覧から外しました」と出て、一覧から消える。
- [ ] 再起動しても一覧が残る（`%LOCALAPPDATA%\Linote\settings.json` の `recent_files`）。存在確認のために起動が遅くならない。
- [ ] 複数のファイルを続けて開く（またはドロップする）操作の後でも、一覧が正しい順で保存される。

### 再読み込み・閉じる

- [ ] ファイル > ディスクから再読み込み: 別のエディターで書き換えたファイルを、Linote で読み直せる。未変更なら確認なし。
- [ ] 未保存の変更があるときは確認が出て、「いいえ」なら何も変わらず、「はい」なら変更が失われてディスクの内容になる。
- [ ] 外部変更の警告（「外部で変更」）が出ているタブで再読み込みすると、警告が消えて上書き保存できる。
- [ ] 無題・メモのタブでは再読み込みできない旨が出る。
- [ ] ほかのタブをすべて閉じる: アクティブなタブだけが残る。未保存のタブは 1 つずつ確認が出て、「取り消し」でそこで止まる。
- [ ] すべて閉じる: 全部閉じて空の新規タブが 1 つ残る。未保存の確認が出る。

### 新しいウィンドウ

- [ ] Ctrl+Shift+N（ファイル > 新しいウィンドウ）で、別のウィンドウが新しいプロセスで起動する（タスクマネージャーで 2 プロセス）。
- [ ] 2 つのウィンドウで同じ設定・メモを使え、一方でメモを編集して閉じても他方の復元データ・メモが壊れない。
- [ ] 2 つ目のウィンドウの起動時に、1 つ目の未保存文書の復元データを「復元しますか」と尋ねない（ロック中の復元データは対象外）。

### 保存時の文字コード・改行

- [ ] ファイル > 保存時の改行 > CRLF／LF／CR: 本文の改行が変換され、ステータスバーの改行表示が変わり、タブが未保存になる。保存したファイルをバイナリエディターで見て、指定の改行だけになっている。Ctrl+Z で変換前に戻る。
- [ ] ファイル > 保存時の文字コード: UTF-8／UTF-8 (BOM 付き)／UTF-16 LE／UTF-16 BE／Shift_JIS (CP932) を選ぶと、ステータスバーの表示が変わり、タブが未保存になる。保存したファイルのバイト列が指定のとおり（UTF-16 は BOM 付き）。
- [ ] CP932 に変換できない文字（絵文字など）を含むときは、保存時に「変換できない文字」の確認が出る。
- [ ] 保存時の文字コードを変えたあと、そのファイルを Linote で開き直すと、同じ文字コード・改行で開く。
- [ ] メモのタブでは、保存時の文字コード・改行を選んでも、使えない旨が状態表示に出て何も変わらない。

### パス

- [ ] フルパスをコピー: クリップボードにフルパスが入り、メモ帳などに貼り付けられる。無題の文書では案内が出る。
- [ ] エクスプローラーで表示: エクスプローラーが開き、そのファイルが選択されている。空白・日本語・`&` を含むパスでも選択できる。

## U2 表示の改善

Wine＋Xvfb の自己診断では、設定が編集欄の Scintilla の状態（折り返しモード、右余白、ガイド線の桁、タブ幅、空白・改行の表示、拡大、文字サイズ）と巨大ファイルのビューの行番号欄に反映され、設定ファイルに保存されること、桁指定でちょうどの桁数が折り返されないことまでを確認している。見た目は実機で確かめる。

### 折り返し

- [ ] 表示 > 折り返し > ウィンドウ幅で折り返す（単語単位）: 長い行（英文）がウィンドウ幅で単語の切れ目で折り返され、ウィンドウの幅を変えると折り返しが追従する。横スクロールバーが出ない。
- [ ] 文字単位: 英単語の途中でも右端で折り返す。日本語の長い行が右端で折り返される。
- [ ] 折り返した 2 行目以降が、元の行と同じ深さのインデント（行頭の空白）で表示される。
- [ ] 指定した桁で折り返す...: 入力欄（既定 80）に 40 と入力すると、等幅フォントで半角 40 文字（`0` を 40 個）の行は折り返されず、41 個で折り返される。ガイド線が 40 桁目の右端に縦線で出る。ウィンドウを広げても 40 桁のまま。狭めると、ウィンドウ幅で折り返す。
- [ ] 桁指定で、行数が増えて行番号の桁が増えたとき（99 → 100 行、999 → 1000 行）や、拡大・縮小、フォント変更のあとでも、折り返し位置の桁が保たれる（ガイド線との位置関係が変わらない）。
- [ ] 桁指定の入力欄で 5 や abc、取り消しを入力しても設定が変わらず、状態表示に案内が出る。
- [ ] 折り返し桁のガイド線をオフにすると線が消える。桁指定以外ではそもそも線が出ない。
- [ ] 折り返しを変えたあと、別のタブに切り替えても同じ折り返しになる（全タブに適用）。再起動しても維持される。
- [ ] 折り返し有効のとき、Home／End、上下キーが表示行単位で動く（Scintilla の標準動作）。

### 書体・拡大・縮小

- [ ] 表示 > フォント...: 標準のフォント選択ダイアログが出て、書体とサイズを選ぶと本文に反映される（行番号の欄の幅も追従する）。取り消しで変わらない。再起動しても維持される。
- [ ] 既定のフォントに戻す: Cascadia Mono（なければ Consolas／MS Gothic）の 11 pt に戻る。
- [ ] Ctrl+マウスホイールで拡大・縮小でき、状態が保存される（再起動で維持）。Ctrl+Plus（日本語配列では Ctrl+;、英語配列では Ctrl+= と Ctrl+Shift+=）、Ctrl+Minus、テンキーの Ctrl+＋／−、Ctrl+0（元に戻す）が効く。
- [ ] 拡大した状態で桁指定の折り返しの桁位置がずれない。
- [ ] 高 DPI／DPI の異なるモニター間の移動で、書体の大きさ・折り返しが崩れない。

### 表示の切り替え

- [ ] 空白とタブを表示: スペースが点、タブが矢印で表示される。改行記号を表示: CRLF／LF／CR の記号が行末に出る。どちらもダーク／ライトの両方で読める色。
- [ ] 行番号を表示（オフ）: 通常のタブで行番号の欄が消える。巨大ファイル（`scripts/gen-large-fixtures.py` で作ったもの）のタブでも行番号の欄が消え、本文が左端へ寄り、選択・スクロール・検索のヒット位置がずれない。オンに戻すと両方とも戻る。隠したまま巨大ファイルを開いても隠れている。再起動で維持される。
- [ ] 現在行の強調: カーソルのある行の背景が変わる。オフにすると消える（ダーク／ライトの両方）。
- [ ] 対応する括弧の強調: `(` `)` `[` `]` `{` `}` のすぐ前後にカーソルを置くと、括弧と対応先が強調される。対応のない括弧は別の（エラー系の）強調。オフで消える。
- [ ] 表示メニューの項目の印（チェック）が現在の設定と一致する（折り返し、タブ幅、各切り替え）。

### タブ・インデント

- [ ] タブ幅 2／4／8: 開いている文書のタブ文字の幅が変わる。新しいタブ・開き直した文書にも同じ幅。再起動で維持される。
- [ ] タブをスペースで入力（オン）: Tab キーでタブ幅ぶんの位置までスペースが入る。選択範囲に Tab（Scintilla の標準でインデント）、Shift+Tab も動く。
- [ ] 自動インデント（オン）: 行頭にスペース・タブのある行の末尾で Enter すると、次の行が同じ空白で始まる。IME で確定した直後の Enter でも同様。オフにすると引き継がない。
- [ ] 日本語入力（IME）変換中の表示位置が、拡大・フォント変更のあとでもずれない。

### 設定ファイル

- [ ] `%LOCALAPPDATA%\Linote\settings.json` の `view` に変更が反映され、手で `wrap` を `"column"`、`wrap_column` を 100 に書き換えて起動すると、そのとおりに動く。不正な値（`"wrap": "x"`、`tab_width` が 3 など）は既定値として読まれ、ほかの設定は失われない。
