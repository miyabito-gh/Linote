# 2026-11-14 コード・エディタUX確認

対象: 初期環境の `2301c0d` から調査し、GitHub最新の `main`（0.1.6、`8f0b4a7`）へ統合したうえで、保存・復元、編集・検索、設定・タブを3担当に分けて確認。機能の網羅的な保証ではなく、具体的な操作で再現する不具合を優先した。Windows 11実機の評価は含まない。

## 発見して修正した問題

| 優先度 | 操作と問題 | 対応 |
|---|---|---|
| P1 | 不正バイトを置換して開いた文書がクラッシュ復元されると、不可逆変換の保存警告が消える | 復元データに警告状態を保持。旧形式で置換文字がある場合も確認する |
| P2 | 保存確認に承諾した後、保存が失敗すると次回の警告が出ない | 保存成功後だけ警告状態を解除 |
| P2 | カーソル位置や分割検索の端が `^`・`$`・単語境界と誤認される | UTF-8の前後文脈を含め、実際の検索開始位置から照合 |
| P2 | 単語途中の選択を「単語単位」で置換できる | 単体置換も前後文脈を照合。選択範囲内の検索仕様は維持 |
| P2 | 別ウィンドウの設定変更が履歴追加や終了時保存で戻る | プロセス間ロック内で再読込・項目単位の差分反映・原子置換。保存失敗時は差分の基準を進めない |
| P2 | 設定保存の待機中に手動再読込すると、待機中の古い設定が外部変更を戻す | 再読込は保存完了後に延期 |
| P2 | 別ページの数値エラーに対し、非表示の入力欄へフォーカスを設定する | 対象ページを表示して入力欄を選択・スクロール |

## 小さな操作改善

多数のタブを開くと隠れたタブへマウスだけで移れなかったため、タブバー上のホイールで前後へ移動できるようにした。高精度ホイールの差分を累積し、端では折り返さず、本文上のホイールは消費しない。

## 検証と残件

回帰テストを検索、復元、設定保存、実際の設定コントロール、GUI自己診断に追加。最終結果は `docs/PLAN.md` の同日記録を参照。

Windows 11実機では、IMEの確定・変換中の操作、異なるDPIのモニター間移動、フォーカスとタブホイール、WebView2の表示、印刷、グローバルショートカット、100 MiB編集・1 GiB閲覧の応答性を引き続き確認する。Wineの成功でこれらの実機確認を代替しない。

既知の制限として巨大モードのUTF-8限定が残る。プレビューのスクロール保持とファイルIDによる外部変更検知は0.1.3で改善済みであり、今回の未対応事項には含めない。タブ一覧の専用ボタン・ツールチップなどの見つけやすさは今後の改善候補。Shift+F10／メニューキーの本文メニューがキャレット付近ではなくマウス位置に出る点も、軽微な改善候補として残る。
